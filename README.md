# WEDE-Part3

This repository contains the deployment files for The Soul Society Vault Portfolio (Part 2) submitted in partial fulfillment of the WEDE5020POE module outcomes for the 2026 academic year. This production-ready single-page web application utilizes structured, semantic HTML5 metadata tags optimized for search engine indexing pipelines alongside an advanced mobile-first architecture built natively via fluid CSS Grid configurations. Interactive capabilities are powered by a vanilla JavaScript event engine that implements an asynchronous product search filter, a multi-category inventory sort dashboard, and a fluid lightbox gallery framework. 

Furthermore, the application coordinates spatial data tracking outcomes by integrating the OpenStreetMap-supported Leaflet.js interactive map API directly into the branch contact profile coordinates.
